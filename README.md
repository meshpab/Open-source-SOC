# Open-Source SOC

## Overview

This repository documents the design, deployment, and integration of an open-source Security Operations Center (SOC) stack suitable for small and medium-sized organizations.

The project demonstrates how enterprise-grade security monitoring can be achieved using free and open-source technologies.

## Objectives

- Deploy a secure network firewall using pfSense.
- Configure Snort as a Network Intrusion Detection and Prevention System.
- Deploy Wazuh SIEM for centralized log collection and security monitoring.
- Integrate network and endpoint security into a unified monitoring platform.
- Simulate real-world cyber attacks and investigate security events.
